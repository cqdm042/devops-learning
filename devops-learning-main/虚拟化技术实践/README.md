# 虚拟化技术实践

## 项目介绍

通过虚拟化软件搭建个人测试环境，学习虚拟机创建、资源配置以及虚拟网络管理等基础知识。

## 使用技术

- VMware Workstation
- Windows 11
- Windows / Linux 虚拟机环境

## 实践内容

### 1. 虚拟机环境搭建

- 创建和管理虚拟机实例
- 配置虚拟机 CPU、内存、磁盘资源
- 安装不同操作系统环境进行测试

### 2. 虚拟网络配置

- 理解 NAT、桥接等网络模式
- 配置虚拟机网络连接
- 排查虚拟机网络访问问题

### 3. 运行环境优化

- 根据应用需求调整虚拟机资源分配
- 分析 CPU、内存占用情况
- 处理虚拟机运行过程中的异常问题

## 实践成果

完成个人虚拟化测试环境搭建，用于：

- 软件测试
- Linux学习
- 服务部署实验
- 网络环境测试

## 学习收获

掌握虚拟机基础管理流程，了解虚拟化资源分配、网络配置以及测试环境搭建方法。
