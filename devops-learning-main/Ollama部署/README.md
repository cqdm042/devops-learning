# Ollama 本地大模型部署实践

## 项目介绍

在个人电脑环境中部署本地大语言模型运行环境，学习开源大模型的本地化部署、模型管理以及推理测试流程。

## 使用技术

- Ollama
- 开源大语言模型（LLM）
- Windows 11
- GPU / CPU 推理环境

## 实践内容

### 1. Ollama环境搭建

- 安装并配置 Ollama 运行环境
- 熟悉本地模型运行流程
- 配置模型存储路径

### 2. 模型管理

- 下载并运行开源大语言模型
- Qwen系列模型
- DeepSeek系列模型
- 管理本地模型列表
- 测试不同模型的运行效果

### 3. 本地推理测试

- 通过命令行调用模型
- 测试文本生成效果
- 了解模型大小、量化方式对运行性能的影响

## 项目成果

完成个人电脑本地大模型运行环境搭建，实现：

- 本地运行开源大语言模型
- 模型下载与管理
- 本地AI对话测试

## 学习收获

通过实践了解了本地AI部署的基本流程，包括模型运行环境搭建、资源占用分析以及大模型推理过程。
